Claude Code 安装说明
====================

版本: 2.1.123 (Claude Code)
文件: claude.exe (253MB, 自包含免安装)

安装步骤:
----------

1. 将 claude.exe 复制到目标电脑的以下目录:
   C:\Users\<你的用户名>\.local\bin\

   (如果目录不存在，手动创建)

2. 确保该目录在系统 PATH 中:
   - 按 Win+R，输入 sysdm.cpl
   - 高级 → 环境变量
   - 在用户变量 Path 中添加: %USERPROFILE%\.local\bin

3. 打开新的命令行窗口，运行:
   claude --version

   如果显示版本号，安装成功。

首次运行:
---------
- 第一次运行 claude 会自动创建所需目录和配置文件
- 按提示完成登录认证即可使用

可选: 迁移配置
----------
如果要保留旧电脑的设置(项目记忆、插件等)，可以将旧电脑的
C:\Users\<用户名>\.claude 目录复制到新电脑同一位置。

注意:
-----
- 需要 Windows 10 或更高版本
- 如果遇到防火墙提示，请允许 claude.exe 联网
- 此版本为离线安装包，免去下载安装步骤
