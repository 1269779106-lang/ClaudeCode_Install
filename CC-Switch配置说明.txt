CC-Switch 配置说明（中文）
========================

版本: v3.14.1 (便携版)
用途: Claude Code API 代理切换工具，管理多个 API 密钥和代理配置

-----------------------------------

一、安装方法
----------

方法1: 便携版安装（推荐）
  1. 解压 CC-Switch-v3.14.1-Windows-Portable.zip 到任意目录
  2. 运行 cc-switch.exe 即可
  3. 程序会自动创建配置文件夹：%USERPROFILE%\.cc-switch\

方法2: 直接使用主程序
  1. 将 cc-switch.exe 复制到任意目录
  2. 运行后会自动创建 portable.ini 启用便携模式

-----------------------------------

二、配置文件位置
--------------

主配置目录: C:\Users\<用户名>\.cc-switch\
├── cc-switch.db      # 配置数据库
├── logs\             # 日志目录
│   └── cc-switch.log
└── config\           # 配置文件（如有）

-----------------------------------

三、基本使用
----------

1. 启动 CC-Switch
   - 双击 cc-switch.exe 启动
   - 首次运行会显示配置向导

2. 添加 API 配置
   - 点击 "添加配置" 或 "+" 按钮
   - 填写以下信息：
     * 配置名称：自定义名称（如：官方API、代理1）
     * API Key：你的 Anthropic API 密钥
     * API Base URL：API 端点地址
       - 官方：https://api.anthropic.com
       - 代理：按代理服务商提供的地址填写
     * 模型选择：可选择默认使用的模型

3. 切换配置
   - 在主界面点击要使用的配置
   - 状态栏会显示当前激活的配置
   - Claude Code 会自动使用当前激活的配置

-----------------------------------

四、与 Claude Code 集成
---------------------

CC-Switch 通过设置环境变量来控制 Claude Code 的 API 配置：

1. 自动模式（推荐）
   - CC-Switch 启动后会自动设置环境变量
   - 新打开的终端窗口会自动使用当前配置

2. 手动模式
   如需手动设置环境变量：
   ```
   set ANTHROPIC_API_KEY=你的API密钥
   set ANTHROPIC_BASE_URL=你的API地址
   ```

3. 验证配置
   打开新的命令行窗口，运行：
   ```
   claude --version
   ```
   确认 Claude Code 能正常连接

-----------------------------------

五、常见问题
----------

Q1: Claude Code 连接失败怎么办？
A1: 检查以下几点：
    - API Key 是否正确
    - API Base URL 是否可访问
    - 网络连接是否正常
    - 查看日志：%USERPROFILE%\.cc-switch\logs\cc-switch.log

Q2: 如何切换不同的 API 配置？
A2: 在 CC-Switch 主界面点击对应的配置即可切换

Q3: 配置保存在哪里？
A3: 配置保存在 %USERPROFILE%\.cc-switch\cc-switch.db 数据库中

Q4: 便携版和安装版有什么区别？
A4: 便携版所有配置都在程序目录，方便迁移；安装版配置在用户目录

Q5: 如何备份配置？
A5: 备份 %USERPROFILE%\.cc-switch\ 整个文件夹即可

-----------------------------------

六、高级配置
----------

1. 多配置管理
   - 可以添加多个 API 配置
   - 为不同项目使用不同配置
   - 支持配置分组和标签

2. 代理设置
   如需使用 HTTP 代理：
   - 在 CC-Switch 设置中配置代理地址
   - 或设置系统环境变量：
     set HTTP_PROXY=http://代理地址:端口
     set HTTPS_PROXY=http://代理地址:端口

3. 自动启动
   如需开机自动启动 CC-Switch：
   - 创建 cc-switch.exe 的快捷方式
   - 将快捷方式放入启动文件夹：
     Win+R 输入 shell:startup

-----------------------------------

七、卸载方法
----------

1. 删除程序文件：
   - cc-switch.exe
   - portable.ini（如有）

2. 删除配置目录：
   C:\Users\<用户名>\.cc-switch\
   （如需保留配置可跳过此步）

3. 清理环境变量（如手动设置过）：
   - 删除 ANTHROPIC_API_KEY
   - 删除 ANTHROPIC_BASE_URL

-----------------------------------

八、技术支持
----------

- 查看日志排查问题：%USERPROFILE%\.cc-switch\logs\cc-switch.log
- 确保 Claude Code 已正确安装并可运行
- 检查网络连接和防火墙设置
