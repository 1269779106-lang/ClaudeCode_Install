CC-Switch 配置说明（中文）
========================

版本: v3.14.1 (便携版)
用途: Claude Code / Codex / Gemini API 代理切换工具，管理多个 API 配置

-----------------------------------

一、安装方法
----------

方法1: 便携版安装（推荐）
  1. 解压 CC-Switch-v3.14.1-Windows-Portable.zip 到任意目录
  2. 运行 cc-switch.exe 即可
  3. 程序会自动创建配置文件夹：%USERPROFILE%\.cc-switch\

方法2: 直接使用主程序
  1. 将 cc-switch.exe 复制到任意目录
  2. 运行后会自动创建 portable.ini 启用便携模式

-----------------------------------

二、配置文件位置
--------------

主配置目录: C:\Users\<用户名>\.cc-switch\
├── cc-switch.db      # 配置数据库（SQLite）
├── settings.json     # 全局设置
├── logs\             # 日志目录
│   └── cc-switch.log
└── backups\          # 自动备份目录

-----------------------------------

三、支持的 AI 提供商
-------------------

CC-Switch 支持以下 AI 客户端的配置管理：

1. Claude Code (app_type: claude)
   - 官方 Anthropic API
   - 第三方代理（DeepSeek、MIMO 等兼容接口）

2. Codex (app_type: codex)
   - OpenAI 官方（支持 ChatGPT 登录或 API Key）
   - 第三方代理

3. Gemini (app_type: gemini)
   - Google 官方 API

六、高级配置项
------------

1. 多模型切换
   每个配置可以指定不同的模型：
   - ANTHROPIC_MODEL: 主模型
   - ANTHROPIC_DEFAULT_SONNET_MODEL: Sonnet 替代模型
   - ANTHROPIC_DEFAULT_HAIKU_MODEL: Haiku 替代模型
   - ANTHROPIC_DEFAULT_OPUS_MODEL: Opus 替代模型

2. 推理强度设置（Codex）
   model_reasoning_effort = "low" | "medium" | "high" | "xhigh"

3. 上下文窗口配置
   model_context_window = 1000000        // 上下文 token 数
   model_auto_compact_token_limit = 900000  // 自动压缩阈值

4. 项目信任级别
   trust_level = "trusted"               // 完全信任
   trust_level = "untrusted"             // 需要确认

5. 插件配置（Codex）
   [plugins."browser-use@openai-bundled"]
   enabled = true

6. 通用配置开关
   commonConfigEnabled: true/false        // 是否使用通用配置
   endpointAutoSelect: true/false         // 自动选择端点

7. 使用量查询脚本
   "usage_script": {
     "enabled": true,
     "language": "javascript",
     "templateType": "balance",           // 余额查询模板
     "autoQueryInterval": 5               // 自动查询间隔（分钟）
   }

七、故障转移配置
--------------

1. 配置故障转移队列
   - 设置 in_failover_queue = 1 加入故障转移队列
   - 主配置失败时自动切换到队列中的下一个配置

2. 成本倍率设置
   cost_multiplier = "1.0"               // 成本计算倍率

3. 使用限制
   limit_daily_usd = 10.0                // 每日使用限额（美元）
   limit_monthly_usd = 100.0             // 每月使用限额（美元）

八、与 Claude Code 集成
---------------------

CC-Switch 通过设置环境变量来控制 Claude Code：

1. 自动模式（推荐）
   - 在 CC-Switch 中激活配置
   - 新打开的终端窗口自动使用当前配置

2. 手动模式
   set ANTHROPIC_API_KEY=你的API密钥
   set ANTHROPIC_BASE_URL=你的API地址
   set ANTHROPIC_MODEL=模型名称

3. 验证配置
   claude --version
   claude "测试连接"

九、常见问题
----------

Q1: 如何添加新的 API 配置？
A1: 打开 CC-Switch → 点击 "+" → 选择 API 类型 → 填写配置信息

Q2: 如何切换配置？
A2: 在主界面点击要使用的配置，或使用快捷键切换

Q3: 配置保存在哪里？
A3: %USERPROFILE%\.cc-switch\cc-switch.db (SQLite 数据库)

Q4: 如何备份配置？
A4: 备份 %USERPROFILE%\.cc-switch\ 整个文件夹
    或使用 backups\ 目录中的自动备份

Q5: 日志在哪里？
A5: %USERPROFILE%\.cc-switch\logs\cc-switch.log

Q6: 连接失败怎么办？
A6: 检查：
    - API Key 是否正确
    - Base URL 是否可访问
    - 网络连接是否正常
    - 查看日志排查具体错误

十一、卸载方法
------------

1. 删除程序文件
2. 删除配置目录：%USERPROFILE%\.cc-switch\
3. 清理环境变量（如手动设置过）
